# Changelog

## 1.2 – 2026-10-13
- View settings are inherited: a folder without its own settings uses those of the nearest configured parent. Merely visiting a folder no longer freezes its view.
- New **global view** option (Preferences ▸ General, View Options): one view for all folders.
- Double-click a column divider in List view to auto-size the column.
- Preferences ▸ Advanced: choose **System traffic lights** or **Aqua Glow**.
- Dual pane: **F3** (View / Quick Look) and **F4** (Edit in TextEdit) added to the footer, keys and X-Mode menu.
- Documentation in `docs/` translated to English.
- About box now states the app icon is author-supplied and not GPL-covered.

## 1.1.1 – 2026-10-13
- App icon: the author-supplied icon (AI-generated, not GPL-covered) is bundled again; the original drawing remains available via `Reference/make_icon.py`.

## 1.1 – 2026-10-13
- Clean, redistributable artwork: removed third-party/Apple-derived icons and the AI-generated app icon; all icons are original drawings, new original app icon.
- New preferences page **Custom Icons**: replace any sidebar icon with a transparent 64 × 64 PNG (export templates, import folder, reset).
- Time Machine volumes get their own sidebar icon.

## 1.0 – 2026-10-13
First release.
- Four views (icon, list, column, Cover Flow), sidebar, search with smart folders, “All My Files”, Quick Look, Get Info, preferences.
- File operations with metadata preservation, conflict handling, undo/redo, Trash with Put Back, burn folders.
- X-Mode: tabs or dual pane, batch rename, transfer queue, folder sizes on demand, per-pane history and favorites, “Terminal Here”.
- Optional Aqua traffic lights, colored sidebar icons, custom app icon (PNG 256 × 256).
